## Phase I: Design the game (20–30 min)

### 1.1 Brainstorm with the AI instructor
- [ ] Press **Talk** on the mission page and complete the session.
- [ ] Note the plan it gives you.
- **Done when:** the plan is pasted into the design record, §2.

### 1.2 Choose the game concept
- [ ] Compare the options in design record §3 and pick one.
- Good multiplayer concepts are: **quick to learn** (rules fit in 2 sentences), **short rounds** (under 1 minute), **simultaneous secret choices** revealed together, **2–6 players**.
- **Done when:** design record §3 shows the chosen concept and why.

### 1.3 Write the rules a stranger can follow
- [ ] Write the rules in 3–5 short lines, without you there to explain them.
- [ ] Test them: read them to someone; can they play without questions?
- **Done when:** design record §4 is filled in.

### 1.4 Define the game flow and what must stay in sync
- [ ] Lobby → join with room code → start → rounds → reveal → scores → winner → play again.
- [ ] List what **every player must see at the same time** (players list, timer, phase, reveals, scores).
- **Done when:** design record §5 is filled in.

## Phase II: Build in ChatGPT *(brief)* (60–90 min)

### 2.1 Let ChatGPT interview you
- [ ] Start a **Work mode** chat and follow the mission's prompts; answer ChatGPT's design questions using design record §4–§5.
- **Done when:** ChatGPT has a complete picture of the game.

### 2.2 Approve the plan before it builds
- [ ] Read ChatGPT's plan line by line. Check it against your rules and sync list.
- [ ] Push back on anything missing or extra **before** approving.
- **Done when:** the plan matches design record §4–§5, and you've logged any changes in §6.

### 2.3 First build
- [ ] Let it build; get the **public link**.
- **Done when:** the game opens at a link without login or install.

### 2.4 Multi-device test
- [ ] Open the link on **at least 2 devices** (e.g. laptop + phone, or two browsers / one incognito).
- [ ] Run the checklist in design record §7: join with the room code, everyone sees the same phase and timer, choices stay hidden until the reveal, scores match on every screen, refresh or late join, play again.
- **Done when:** every row in §7 passes.

### 2.5 Debug precisely
- [ ] For each problem, tell ChatGPT **exactly** what happened: which screen, which step, expected vs. actual. Use the bug template in §8.
- [ ] Re-test after each fix.
- **Done when:** the bug log (§8) has no open items.

### 2.6 Polish
- [ ] Clear title, rules visible on the join screen, readable on a phone, a fun reveal moment.
- **Done when:** a first-time player understands it without help.
